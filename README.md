# Home renovation

Family pages for the renovation work on the house, published with GitHub Pages.

| Folder | What | Contents |
|---|---|---|
| `model/` | 3D model of the house | Ground floor (before + layout options A–E) and 1st floor (kitchen as it is today or as IKEA planned it, dining, living room). three.js r147 is bundled in the file, so it works offline. Open `model/#ground`, `model/#first`, `model/#both` or `model/#kitchen` to start there. |
| `kitchen/` | 1st floor kitchen project | Review of IKEA's plan, routes and budget, and the full shopping list with links to ikea.com/fr. One self-contained page; the list data is embedded. |
| `hall/` | Ground floor hall project | `plan.html` layouts, work sequence, materials checklist and budget, calendar, permits · `plan.pdf` printable copy · `3d.html` redirects to `model/` |

To add a project, create a new folder with its own `index.html` and add a row to the list in the root `index.html`.

Dimensions are approximate (±10–20 cm) and prices are November 2026 estimates.
