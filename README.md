# Home renovation

Family pages for the renovation work on the house, published with GitHub Pages.

| Folder | Project | Contents |
|---|---|---|
| `hall/` | Ground floor hall | `3d.html` interactive 3D model (three.js r147 bundled, works offline) · `plan.html` layouts, work sequence, materials checklist and budget, calendar, permits · `plan.pdf` printable copy |

To add a project, create a new folder with its own `index.html` and add a row to the list in the root `index.html`.

Dimensions are approximate (±10 cm) and prices are November 2026 estimates.
